# Study Workspace Rules

This repository is a persistent learning workspace, not an application repository.

## Primary goals
- learn technical projects systematically
- produce durable notes and comparison artifacts
- preserve progress so new Claude Code sessions can resume quickly

## Canonical files
Read these first before continuing work:
- study-manifest.md
- current-status.md
- resume/resume-brief.md

## Output policy
Prefer writing durable markdown files over keeping important findings only in chat.

Use these locations by default:
- notes/ for project and module notes
- comparisons/ for cross-project analysis
- stages/ for stage definitions
- progress/ for progress logs
- plans/ for next-step planning
- summaries/ for stable conclusions
- resume/ for handoff files

## Analysis rules
Always distinguish:
- Facts
- Inferences
- Recommendations
- Open Questions

Do not present inference as fact.

## Safety and scope
Do not modify studied project code unless explicitly requested.

This workspace is for analysis, learning, comparison, and teaching-oriented notes.

## Continuity
After meaningful progress, update:
- current-status.md
- resume/resume-brief.md

When stage boundaries change, reflect that in the written state files.
